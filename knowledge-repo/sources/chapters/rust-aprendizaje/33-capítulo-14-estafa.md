# Capítulo 14:: estafa

Introducción
rustup administra su instalación de óxido y le permite instalar diferentes versiones, que pueden
configurarse e intercambiarse fácilmente.
Examples
Configurando
Instale la cadena de herramientas con
curl https://sh.rustup.rs -sSf | sh
Ya deberías tener la última versión estable de óxido. Puedes comprobarlo escribiendo
rustc --version
Si quieres actualizar, simplemente ejecuta
rustup update
