# 11.6 Conclusión

En este capítulo nos las hemos apañado para resolver el problema de gestión de
dependencias de datos. Este problema aparece con frecuencia. Cada gestor de estados
tiene su propia manera de lidiar con ello. Las alternativas basadas en Flux y Redux
esperan que seas tú quien gestione las referencias. Soluciones como MobX integran
la gestión de referencias. La normalización de los datos puede hacer que este tipo de
operaciones sean más sencillas.
En el próximo capítulo nos centraremos en añadir una funcionalidad que no tenemos
en la aplicación: la edición de carriles. También haremos que la aplicación tenga un
mejor aspecto. Por suerte mucha de la lógica que necesitamos ya ha sido desarrollada.
