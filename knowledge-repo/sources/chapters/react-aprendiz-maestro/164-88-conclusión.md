# 8.8 Conclusión

En este capítulo hemos debatido la idea básica de qué es la arquitectura Flux y hemos
comenzado a migrar nuestra aplicación a ella. Hemos dejado todo lo relacionado con
la gestión del estado tras un adaptador para poder modificar el código sin tener que
cambiar nada relacionado con la vista. El paso siquiente será definir un almacén para
nuestra aplicación y definir las acciones que lo puedan manipular.
