# WCAG

Focus Visible 2.4.7 (Understanding 2.4.7)
Consistent Identification 3.2.4 (Understanding 3.2.4)
User Story:
Challenges faced by someone with a limited ability to use a mouse
Challenges faced by an older user with hand tremors
Ensure that navigation across pages within a website has consistent naming, styling, and positioning.
Provide more than one method of website navigation, such as a site search or a site map. Help users
understand where they are in a website or page by providing orientation cues, such as breadcrumbs
and clear headings.
