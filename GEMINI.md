## Ciclo de trabajo obligatorio

Para CADA tarea, sigue este ciclo en orden. No puedes saltarte ningún paso:

```
1. CONTEXT → analyze_project (MCP) + leer AGENTS.md
2. ANALYZE → workflow_check (MCP) para ver estado
3. PLAN → work_context_plan <task> (MCP) — prerrequisito para implementar
4. RESEARCH → knowledge_search o recall o context_unified (MCP)
5. IMPLEMENT → codificar, usar anotaciones
6. VALIDATE → validate o lint_file (MCP) — prerrequisito para cerrar
7. INTEGRATE → actualizar AGENTS.md si toca
8. LEARN → documentar aprendizajes
9. CLOSE → work_context_close (MCP)
```

Antes del paso 5 (IMPLEMENT), DEBES haber ejecutado `work_context_plan <task>` (MCP tool). No implementes nada sin un plan registrado.
