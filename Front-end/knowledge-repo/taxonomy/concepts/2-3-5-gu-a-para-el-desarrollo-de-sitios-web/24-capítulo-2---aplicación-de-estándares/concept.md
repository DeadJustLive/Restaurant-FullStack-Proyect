Estructura de los documentos web
El estándar HTML determina que los contenidos deben ser ubicados mediante el
uso de etiquetas (del inglés "tag") que especifica la característica del mismo y que
se identifican porque usan los corchetes angulados “<" y “>" para designarlas

hasta aquellas que sirven para explicar el comportamiento o características de una
