¿Por qué usar la inyección de dependencia
Rápido proceso de desarrollo	1.
Desacoplamiento	2.
Prueba de unidad de escritura	3.
Rápido proceso de desarrollo
Cuando se usa el desarrollador de nodos de inyección de dependencias, se puede acelerar su
proceso de desarrollo porque después de DI hay menos conflicto de código y es fácil administrar
todos los módulos.
Desacoplamiento
Los módulos se vuelven menos acoplados, entonces es fácil de mantener.
Prueba de unidad de escritura
Las dependencias codificadas pueden pasarlas al módulo y, a continuación, es fácil escribir la
prueba de unidad para cada módulo.
