# 7. Dando Estilo a la Aplicación

de Notas
Estéticamente hablando, nuestra aplicación se encuentra en un estado bastante
precario. Algo tendremos que hacer, ya que las aplicaciónes más divertidas de utilizar
son aquellas que son visualmente más atractivas. En nuestro caso vamos a utilizar
un estilo a la vieja usanza.
Para ello esparciremos algunas clases CSS y aplicaremos estilo en base a los selectores.
El capítulo Dando estilo a React discute otras aproximaciones con mayor detalle.
