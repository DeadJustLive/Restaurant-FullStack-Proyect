# 5. Comprendiendo los

Componentes de React
Hasta donde hemos visto, los componentes de React son muy sencillos: Tienen un
estado interno y aceptan propiedades (props). Aparte de esto, React facilita puntos de
enganche que te permitirán hacer cosas más avanzadas, entre las que que se incluyen
los métodos que gestionan el ciclo de vida y las referencias (refs). También existe
una serie de propiedades y de métodos de los que te conviene ser consciente.
