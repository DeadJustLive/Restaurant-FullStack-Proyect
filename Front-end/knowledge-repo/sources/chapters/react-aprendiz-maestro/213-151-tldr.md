# 15.1 TL;DR

• propTypes2 son estupendos. Utilízalos para mejorar la mantenibilidad de tu
aplicación.
• propTypes te mostrarán algunos pequeños errores durante el desarrollo, pero
se descartan en la compilación para producción para mejorar el rendimiento.
• Flow3 va un paso más allá. Te da una sintaxis básica que te permite tipar
gradualmente tu código JavaScript.
• Mientras que flow es un analizador estático que debes ejecutar de forma
separada, babel-plugin-typecheck4 puede hacer verificaciones durante el desa-
rrollo.
• El lenguaje TypeScript5 de Microsoft es otra alternativa más. Desde la versión
1.6 tiene soporte para JSX.
Compra el libro6 para más detalles.
