# 3. 	Para cada operación modificadora se escriben tantas ecuaciones como sean necesarias para garantizar que todo

término de TCons(g) sea congruente a algún término de TGen(g). Una estrategia habitual es poner la operación
modificadora como la más externa de un término y descomponer cada parámetro de tipo correspondiente a g en
todos sus posibles patrones formados con las operaciones generadoras. Por ejemplo, la cuarta ecuación de la
especificación 	bolsasDeNaturales, 	considerando 	Gen(bolsa) 	= 	{[],[_],_∪_} 	como 	conjunto 	de
generadoras, es de esta clase. También las tres ecuaciones de la especificación naturales_3 vista antes
pertenecen a esta clase.
