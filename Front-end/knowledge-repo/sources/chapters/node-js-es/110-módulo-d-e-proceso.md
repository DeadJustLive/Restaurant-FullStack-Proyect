# Módulo d: e proceso

Es posible utilizar el módulo de proceso para escribir directamente en la salida estándar de la
consola. Por lo tanto existe el método process.stdout.write . A diferencia de console.log este
método no agrega una nueva línea antes de su salida.
Entonces, en el siguiente ejemplo, el método se llama dos veces, pero no se agrega una nueva
línea entre sus salidas.
