# 6. Conclusiones

Como hemos podido ver Typescript añade algunas cosas interesantes que echamos de menos en Javascript
que ayudaran a mejorar el código y a aumentar la mantenibilidad en proyectos grandes.

debugging o la recolección de trazas. Además de que el tipado puede ayudarnos mucho a la hora de hacer
nuestro código más robusto y además nos ofrece una documentación de lo que hacen nuestras clases y
funciones sin perder las mejores partes de Javascript.
