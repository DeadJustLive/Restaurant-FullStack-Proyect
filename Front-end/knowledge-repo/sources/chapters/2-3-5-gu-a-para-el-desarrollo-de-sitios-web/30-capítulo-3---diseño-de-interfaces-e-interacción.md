> ¿Qué es una interfaz?
Cuando se habla de Sitios Web, se denomina interfaz5 al conjunto de elementos de
la pantalla que permiten al usuario realizar acciones sobre el sitio web que está
visitando. Por lo mismo, se considera parte de la interfaz a sus elementos de
identificación, de navegación, de contenidos y de acción.
Todos ellos deben estar preparados para ofrecer servicios determinados al usuario,
con el fin de que éste obtenga lo que vino a buscar cuando visitó el sitio web. Por
lo anterior, cada uno de los elementos que sean integrados dentro de la interfaz
debe estar pensado para causar un efecto sobre el usuario y deben ser utilizados
con un propósito.
